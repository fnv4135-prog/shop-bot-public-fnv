Профессиональный Telegram-бот для интернет-магазина с полноценной базой данных PostgreSQL, админ-панелью и асинхронной архитектурой.

## 🚀 Демо

Бот: [@smart_tech_inc_bot](https://t.me/smart_tech_inc_bot)  
Пример работы: [Видеодемонстрация](#)

## ✨ Особенности

- **🛒 Полный цикл покупок**: Каталог → Корзина → Заказ → Уведомление админу
- **🗄️ PostgreSQL**: Надёжное хранение данных, транзакции, connection pooling
- **👑 Админ-панель**: Добавление товаров, статистика, управление заказами
- **⚡ Асинхронность**: Высокая производительность на asyncpg + aiogram
- **☁️ Готов к продакшену**: Деплой на Render, мониторинг, логирование

## ✨ Функционал

✅ **Полный цикл продаж:**
- 📱 Интуитивное кнопочное меню
- 🛍️ Каталог товаров с категориями
- 🛒 Корзина с подтверждением очистки
- 📝 Оформление заказов
- 🔔 Уведомление администратора

✅ **Для администраторов:**
- 👑 Защищённая админ-панель (/admin)
- ➕ Добавление товаров через FSM
- 📊 Статистика магазина
- 🔧 Управление товарами

✅ **Для бизнеса:**
- Автоматизация 70% рутинных операций
- Снижение нагрузки на менеджеров
- Круглосуточный прием заказов
- Интеграция с существующими процессами

## 🛠 Технологии

- **Python 3.11+** - основной язык (с асинхронным программированием)
- **Aiogram 3.х** - современный фреймворк для Telegram ботов
- **Render.com** - облачный хостинг с автоматическим деплоем
- **PostgreSQL 15+** - промышленная СУБД
- **asyncpg** - асинхронный драйвер для PostgreSQL
